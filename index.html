About this project

Álvaro Hernández
Finance & Accounting · UC3M Madrid · Class of 2027

FINscope is a full-stack financial intelligence platform demonstrating how modern tooling can deliver institutional-grade equity analysis at near-zero marginal cost.

The backend is a Python serverless API on Vercel combining Finnhub, Alpha Vantage, and FRED in parallel. It computes RSI, MACD, SMA, Altman Z-Score, Piotroski F-Score, and a composite score before synthesising everything via a Goldman Sachs equity research prompt with a 25-sector WACC benchmark table.

The result is an 11-section collapsible report covering business model, 4-year financial history, macro context tailored to the company's geographic exposure, competitor benchmarking, valuation, and scenario analysis.
