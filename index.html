About this project

Álvaro Hernández
Finance & Accounting · UC3M Madrid · Class of 2027

FINscope is a full-stack financial intelligence platform demonstrating how modern tooling can deliver institutional-grade equity analysis at near-zero marginal cost.

The backend is a Python serverless API on Vercel that queries Finnhub in parallel, pulls live macro data from FRED (10Y yield, Fed Funds, VIX), runs quantitative calculations server-side, then passes the full structured dataset to GPT-4o using a Goldman Sachs equity research prompt with a 25-sector WACC benchmark table.

The system generates dynamic methodology caveats per ticker — automatically flagging Z-Score invalidity for banks, cyclicality warnings for energy, and technical limitations when candle data is unavailable.
